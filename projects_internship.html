1. Project - DailyIntern Website

DailyIntern – Web-Based Internship Management System

DailyIntern is a web-based application developed to digitize and manage daily internship activity reporting. The system was designed to replace manual logbooks and paper-based reporting processes commonly used during internship or field practice programs.

The application provides two main roles: Intern and Admin/Supervisor. Interns can record daily activities, submit attendance, write logbooks, and request permissions online. Supervisors can monitor intern progress, validate reports, manage participant data, and generate activity summaries through a centralized dashboard.

The system was developed using the Waterfall software development methodology, starting from requirements analysis, system design, implementation, testing, and deployment. DailyIntern focuses on improving efficiency, data accuracy, transparency, and ease of monitoring internship activities in an organizational environment.

Key Features:

  • User authentication with role-based access (Intern & Admin)
  • Daily activity logbook and attendance tracking
  • Permission and approval management
  • Centralized data management for internship participants
  • Activity monitoring and reporting dashboard

Technologies Used:

  • Backend: Laravel (PHP)
  • Database: MySQL
  • Frontend: HTML, CSS, JavaScript
  • Development Tools: XAMPP, Visual Studio Code, GitHub

Project Type: Internship / Field Practice Project

Role: System Analyst & Web Developer

2. Project - SPKP & SPAK Website

SPKP & SPAK Survey Information System – Web-Based Public Service Evaluation Platform

The SPKP & SPAK Survey Information System is a web-based application developed to support the digital implementation of Public Service Satisfaction Survey (SPKP) and Anti-Corruption Perception Survey (SPAK) at the Secretariat of the Regional House of Representatives (DPRD). The system was designed to replace manual survey processes and improve efficiency, accuracy, and transparency in collecting public feedback.

The application provides two main roles: Administrator and Respondent. Respondents can fill out SPKP and SPAK questionnaires online, while administrators can manage survey questions, monitor responses, analyze results, and generate survey reports through a centralized dashboard.

The system was developed using the Waterfall software development methodology, including requirement analysis, system design, implementation, testing, and deployment. This project focuses on improving the quality of public service evaluation and supporting data-driven decision-making within government institutions.

Key Features:

  • Online SPKP and SPAK survey management
  • Questionnaire and indicator management
  • Public survey submission system
  • Survey result recap and data visualization
  • Centralized dashboard for monitoring and reporting

Technologies Used:

  • Backend: Laravel (PHP)
  • Database: MySQL
  • Frontend: HTML, CSS, JavaScript
  • Development Tools: XAMPP, Visual Studio Code, GitHub

3. Project - Guestly Website

Guestly – Digital Guest Book Website DPRD Kota Bogor

This project is a web-based Digital Guest Book system designed to modernize and streamline the visitor registration process at the Secretariat of DPRD Kota Bogor. The system replaces the conventional manual guest book, which was prone to data loss, inefficiency, and difficulties in monitoring visitor activities.

The application allows visitors to register digitally by filling in visit details such as name, institution, purpose of visit, and meeting agenda. Administrators can manage visitor data, schedules, agendas, incoming and outgoing correspondence, and meeting invitations through a centralized admin dashboard. The system also supports data validation and report generation in Excel and PDF formats to improve transparency and administrative efficiency.

The system was developed using the Waterfall software development methodology, covering requirement analysis, system design, implementation, testing, and maintenance. The Digital Guest Book focuses on improving data accuracy, speeding up the registration process, enhancing security, and supporting structured visitor management within a government institution.

Key Features:

  • Digital visitor registration and guest book management
  • Admin dashboard for monitoring visitors and activities
  • Agenda and meeting schedule management
  • Incoming and outgoing correspondence management
  • Export reports to Excel and PDF
  • Role-based access for Admin and Users

Technologies Used:

  • Backend: Laravel (PHP)
  • Database: MySQL
  • Frontend: HTML, CSS, JavaScript
  • Development Tools: XAMPP, Visual Studio Code, GitHub

Project Type: Internship / Field Practice Project

Role: System Analyst & Frontend Developer
