Egg Viability Sorting Model Using Convolutional Neural Network Based on Eggshell Image

A CNN-based mobile application that automatically classifies whether a chicken egg is viable or not by analyzing its eggshell image. Built with MobileNetV2 via transfer learning and deployed as an offline Flutter app — designed to help farmers sort eggs more objectively without internet dependency.

Accuracy 97.40%
Precision 97%
Recall 97%
Dataset 3,073 images
Model MobileNetV2
Deployment Flutter (Offline)
